This is a **dummy branching strategy** document to describe how we manage branches in Git.

- `main`  
  - Always production-ready.
  - Only release branches and hotfixes are merged here.
- `develop`  
  - Integration branch for upcoming releases.
  - All feature branches merge into this first.
